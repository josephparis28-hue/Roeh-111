# ROEH 111 — Formspree setup and test checklist

Endpoint configured: `https://formspree.io/f/xvkaawre`

1. Open this extracted folder in Visual Studio Code.
2. Run **Live Server** and open `contact.html`.
3. Fill out a test request using your own email. Use a test name and a message that says it is a test; do not enter sensitive information.
4. Select Digital, Restore, and Life in separate test submissions. Observe the status message after each one.
5. In your own Formspree account, confirm every submission appears under this form and check the connected notification inbox.
6. After publishing to GitHub Pages, repeat there. Do not equate a success message alone with confirmed email delivery.
7. Review/update `privacy.html` before collecting real customer details.

The rest of the website, including your working homepage images, has been left unchanged.
